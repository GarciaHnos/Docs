# Precios Web

| Campo | Valor |
| ----- | ----- |
| Tecnología | Java |
| Propósito | Web scraping de precios de la competencia y propios en páginas de supermercados. |
| Repositorio | [gh-com-preciosweb](https://github.com/GarciaHnos/gh-com-preciosweb) |
| Integra con | Sitios web de supermercados (origen), almacenamiento interno a confirmar |

## Qué hace

Programa comercial, no de piso de planta: recolecta precios públicos para comparación.
