# Marcaciones de relojes biométricos

| Campo | Valor |
| ----- | ----- |
| Tecnología | Python |
| Propósito | Lee marcaciones de relojes biométricos y las graba en Integra (accesos). |
| Repositorio | [gh-ind-controlHora](https://github.com/GarciaHnos/gh-ind-controlHora) |
| Integra con | Relojes biométricos, Integra (accesos) |

## Qué hace

A diferencia de Horas Sueldos (liquidación), este proceso apunta al **control de accesos**: las mismas u otras marcaciones entran al módulo de accesos de Integra.
