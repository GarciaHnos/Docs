# Slideshow de indicadores

| Campo | Valor |
| ----- | ----- |
| Tecnología | Java |
| Propósito | Muestra indicadores de Qlik, Shologix e Integra en slideshow automático en sectores productivos. |
| Repositorio | [gh-ind-slideshow](https://github.com/GarciaHnos/gh-ind-slideshow) |
| Integra con | Qlik, Shologix, Integra, pantallas de planta |

## Qué hace

Rotación automática de tableros en pantallas de piso. No graba producción: consume fuentes ya existentes y las muestra.
