# Contactos y responsables

No hay un directorio de personas publicado en este repo. Hasta que el equipo lo complete, usá esta tabla de **dominios** y pedí el nombre concreto a tu referente.

| Dominio | Qué cubre | Dónde empezar |
| ------- | --------- | ------------- |
| Referente de ingreso | Accesos del [primer día](primer-dia.md), buddy, primer ticket | Quien te convocó a IT |
| GitHub org | Invitación a `GarciaHnos`, permisos de repo | [GarciaHnos](https://github.com/GarciaHnos) |
| Documentación | Este sitio MkDocs | Repo [GarciaHnos/Docs](https://github.com/GarciaHnos/Docs) |
| Programas de planta | Relojes, finales de línea, PLC, Integra | Páginas en [Proyectos](../proyectos/relevamientoProgramas/relevamientoProgramas.md) |
| Comercial | Precios web / scraping | [Precios Web](../proyectos/programas/precios-web.md) |
| CI / GitHub Actions | Workflows reutilizables | Repo [GarciaHnos/.github](https://github.com/GarciaHnos/.github) |

## Cómo completar esta página

Cuando un programa tenga dueño claro, agregá una fila con:

- Nombre del responsable
- Canal (mail o grupo interno)
- Repo, si aplica

No publiques contraseñas, tokens ni datos de VPN acá.
